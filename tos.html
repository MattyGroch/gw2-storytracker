Description of Service

GW2 Story Tracker is a free, open-source, client-side web application that displays your Guild Wars 2 story progress using data from ArenaNet's public API. The Application runs entirely in your browser and has no backend server.

Authentication & API Access

The Application offers two ways to authenticate: a Guild Wars 2 API key entered manually, or authorization through gw2.me, a third-party OAuth2 service.

If using an API key, it is stored locally in your browser and is only used to authenticate requests to ArenaNet's API (api.guildwars2.com). You may revoke your API key at any time through ArenaNet's API Key Management.

If using gw2.me, the Application receives a temporary access token and generates short-lived API subtokens on your behalf. You may revoke the Application's access at any time from your gw2.me Authorized Applications page. Use of gw2.me is also subject to gw2.me's own terms.
