Privacy Policy

Last updated: February 21, 2026

Overview

GW2 Story Tracker is an open-source, client-side web application hosted on GitHub Pages. It has no backend server, no database, and no analytics. All processing happens entirely within your browser.

Data We Access

When you provide a Guild Wars 2 API key, your browser makes requests directly to ArenaNet's official API (api.guildwars2.com) to retrieve your account name, character list, story progress, and expansion access. These requests go straight from your browser to ArenaNet — this application never sees, intercepts, or relays the traffic.

Data Stored in Your Browser

  • API Key — stored in localStorage so you don't have to re-enter it on each visit. It is never sent anywhere other than api.guildwars2.com.
  • Session Cache — processed story progress, character info, and your account display name are cached in sessionStorage to speed up repeat page loads. This data is automatically cleared when you close the browser tab.

Cookies, Analytics & Tracking

This application does not use cookies, analytics services, advertising pixels, fingerprinting, or any other form of tracking. No data about your visit is collected or transmitted to any third party.

Third-Party Services

The application loads the following resources from third-party CDNs:

  • React and Babel from unpkg.com
  • Tailwind CSS from cdn.tailwindcss.com
  • Cinzel font from fonts.googleapis.com

These services may log standard web request data (such as IP addresses) according to their own privacy policies. This application has no control over or access to that data.

Clearing Your Data

You can remove all locally stored data at any time by clicking Sign Out within the application, which deletes your API key from localStorage and clears the session cache. You can also clear your browser's site data manually through your browser settings.

Open Source

The complete source code for this application is publicly available on GitHub. You are welcome to audit the code to verify these claims.
